## 博古架放置原则（设计依据，给客户讲解时用）

| 原则 | 做法 |
|---|---|
| 避直射日光 | 只放在**与窗垂直或背向窗**的内墙；不放窗边、不放正对落地窗的墙 |
| 避热源 | 远离壁炉、厨房灶台、射灯；壁炉两侧只放瓷盘/书，不放紫砂 |
| 避油烟 | -1F 是厨房层：只放餐具瓷盘，**紫砂不放 -1F** |
| 灯光 | 格子内**不装灯直打壶身**；用顶部洗墙光或层板下沿的低 UV 2700K 间接光，可调光 |
| 通风 | 开放或背板留缝的格子，下部做带门柜体收纳；地下层配除湿 |
| 动线 | 放在“经过就能看见、但不挡路”的位置：吧台/茶台背后、走廊尽端、楼梯旁 |
